Project Overview:
The NDS is a registered society of car manufacturers, system suppliers and map suppliers. The objective of the initiative is to standardize a physical storage format for car navigation systems.
One of the drawbacks of today's navigation systems is that each system needs its own physical format for navigational data. A direct exchange of map data between different navigation systems is not possible. A standardized binary format, which also provides new features, offers many new opportunities.
The key objective is compatibility and interoperability allowing the exchange of navigational data between systems that comply with Navigation Data Standard. NDS supports standard navigation building blocks like e.g. map display, routing, POIs and location selection as well as advanced navigation content. Plus, NDS provides a common database format and harmonized update concepts for different systems. This ensures flexibility regarding content update, including incremental and partial updates. Moreover, database content can be enriched without changing basic structures.
